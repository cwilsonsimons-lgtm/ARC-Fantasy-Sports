# Meeting memos

Put one transcript per file in this folder. `README.md` and anything starting
with a dot are skipped, so this file won't end up in your prompt.

**Getting the text out of a voice memo.** On iOS 18 or later, open the
recording in Voice Memos, tap the transcript icon, then select all and copy.
Otter, Granola, Zoom and Fathom all have an export or copy-transcript button
too. Paste it into a file here — `.txt` and `.md` both work.

Subtitle exports (`.vtt`, `.srt`) can be dropped in as they are; the cue
numbers and timecodes get stripped out before the prompt is built.

**Name the files by date** — `2026-08-24-roster-screen.md` — because they go
into the prompt in filename order, and the date is what the AI cites when it
tells you which meeting a decision came from. Without a leading date the memos
are still used, they just sort alphabetically and get cited by name.

Don't tidy the transcripts up. The rambling and the half-finished sentences are
what the review reads for intent, and cleaning them up is where you'd
accidentally edit out the thing you forgot to write down.
