# Stories

One story per file. The filename becomes the id the review cites, so
`trade-block.md` gets talked about as `trade-block`. `README.md` and dotfiles
are skipped.

There's no required format. Write them however you already write them — the
whole file goes into the prompt as-is, and the rubric explicitly tells the AI
not to mark you down for not using "As a… I want… so that…".

Paste them straight out of Jira or Linear if that's where they live.
